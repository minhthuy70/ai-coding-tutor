## Làm sạch dữ liệu - Ngoại lệ

❏ Có hai loại ngoại lệ:

❏ Các ngoại lệ đơn biến: các điểm dữ liệu **có giá trị nằm ngoài phạm vi giá trị dự kiến**

❏ Các ngoại lệ đa biến: có các ngoại lệ **phụ thuộc** vào **mối tương quan** giữa **hai biến**

```python
# Drop rows with missing value
data.dropna(inplace = True)

# Remove duplicates
data.drop_duplicates()

# Drop unnecessary columns
data.drop(columns = [list cols], axis = 1)

# Drop/Filter unnecessary rows
data.drop([0, 1], inplace = True)
data[data['column_filter'] == 'abc']

# Re indexing
data.set_index('column', inplace = True)
data.reset_index(drop = True)

# Re-formatting
data['column'] = data['column'].astype(int)

# Correcting inconsistent data
data['column'].replace(old_value, new_value, inplace = True)
```

## Tự động phát hiện ngoại lệ

❏ Tự động phát hiện ngoại lệ:

❏ Yếu tố ngoại lệ cục bộ ([Local Outlier Factor):](https://scikit-learn.org/stable/modules/generated/sklearn.neighbors.LocalOutlierFactor.html) Xác định các ngoại lệ là xác định vị trí của các mẫu ở xa mẫu khác

❏ Rừng cách ly ([Isolation Forest)](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.IsolationForest.html) : Thuật toán phát hiện bất thường dựa trên cây

❏ Xác định hiệp phương sai tối thiểu ([EllipticEnvelope](https://scikit-learn.org/stable/modules/generated/sklearn.covariance.EllipticEnvelope.html)): Tập dữ liệu theo phân phối chuẩn.

[❏ One-class SVM](https://scikit-learn.org/stable/modules/generated/sklearn.svm.OneClassSVM.html) : Phát hiện ngoại lệ không được giám sát

## outlier

Methods for finding out-of-distribution examples in a dataset via scores that quantify how atypical each example is compared to the others.

The underlying algorithms are described in this paper.

## Classes:

| OutOfDistribution ([params]) | Provides scores to detect Out Of Distribution (OOD) examples that are outliers in a dataset. |
| --- | --- |

class cleanlab.outlier.OutofDistribution(params=None)

Bases: object

Provides scores to detect Out Of Distribution (OOD) examples that are outliers in a dataset.

Each example's OOD score lies in [0,1] with smaller values indicating examples that are less typical under the data distribution. OOD scores may be estimated from either: numeric feature embeddings or predicted probabilities from a trained classifier.

To get indices of examples that are the most severe outliers, call find\_top\_issues function on the returned OOD scores.
