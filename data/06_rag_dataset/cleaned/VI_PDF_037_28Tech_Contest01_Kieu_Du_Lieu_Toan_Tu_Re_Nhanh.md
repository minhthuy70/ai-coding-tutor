\- Nếu phương trình có 1 nghiệm hoặc nghiệm kép thì in ra 1 nghiệm duy nhất đó, trường hợp có 2 nghiệm thì in ra nghiệm nhỏ hơn trước. Các nghiệm được in ra với 2 số sau dấu phầy.

Chú ý chia ra 2 trường hợp a = 0, a != 0

Input Format

Dòng duy nhất chứa 3 số a, b, c

Constraints

-100<=a, b, c<=100

Output Format

In ra đáp án của bài toán

Sample Input 0

3 8 4

Sample Output 0

-2.00 -0.67
