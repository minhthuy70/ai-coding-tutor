1. LOCAL MODELS VỚI OLLAMA (Hoàn toàn FREE - Khuyên dùng)
------------------------------------------------------------------------------------------------------------------------------------------------

Cài đặt:
```bash
# Cài Ollama từ https://ollama.ai
ollama pull codellama:7b
ollama pull deepseek-coder:6.7b
```

Ưu điểm:
- Miễn phí 100%
- Không cần API key
- Không gửi code ra ngoài (privacy)
- Chạy local, có thể offline

Nhược điểm:
- Cần máy có GPU/NVRAM tốt (tối thiểu 8GB RAM)
- Chậm hơn API cloud
- Model nhỏ hơn nên chất lượng có thể kém hơn


2. GOOGLE GEMINI FREE TIER
------------------------------------------------------------------------------------------------------------------------------------------------

- Miễn phí: 15 requests/phút, 1.000 requests/ngày
- Đăng ký API key free tại: https://aistudio.google.com/app/apikey
- Model: Gemini 1.5 Flash (nhanh, rẻ) hoặc Pro (chất lượng cao hơn)

Ưu điểm:
- Free tier khá hào phóng
- Chất lượng tốt
- Dễ tích hợp

Nhược điểm:
- Có rate limit
- Gửi code ra cloud (privacy concern)


3. OPENAI API FREE CREDITS
------------------------------------------------------------------------------------------------------------------------------------------------

- Tài khoản mới: $5 free credits
- Sau đó: Phí theo usage (~$0.002/1K tokens)
- Model: GPT-4o-mini (rẻ, đủ tốt cho chấm code)

Ưu điểm:
- Chất lượng cao nhất
- Dễ dùng

Nhược điểm:
- Free credits có hạn
- Sau đó phải trả tiền


4. HUGGING FACE INFERENCE API (FREE TIER)
------------------------------------------------------------------------------------------------------------------------------------------------

- Miễn phí: 1.000 requests/tháng
- Models: CodeLlama, StarCoder, v.v.

Ưu điểm:
- Nhiều model code chuyên dụng
- Free tier

Nhược điểm:
- Rate limit thấp
- Chậm hơn API lớn

2. AI SERVICE ABSTRACTION (Dễ switch provider)
------------------------------------------------------------------------------------------------------------------------------------------------

```python
class AIService:
    def __init__(self, provider="ollama"):
        self.provider = provider
        
    def generate_feedback(self, prompt):
        if self.provider == "ollama":
            return self._call_ollama(prompt)
        elif self.provider == "gemini":
            return self._call_gemini(prompt)
        elif self.provider == "openai":
            return self._call_openai(prompt)
    
    def _call_ollama(self, prompt):
        # Gọi Ollama local API
        import requests
        response = requests.post(
            "http://localhost:11434/api/generate",
            json={
                "model": self.model,
                "prompt": prompt,
                "stream": False
            }
        )
        return response.json()["response"]
    
    def _call_gemini(self, prompt):
        # Gọi Gemini API
        import google.generativeai as genai
        genai.configure(api_key=self.api_key)
        model = genai.GenerativeModel(self.model)
        response = model.generate_content(prompt)
        return response.text
    
    def _call_openai(self, prompt):
        # Gọi OpenAI API
        from openai import OpenAI
        client = OpenAI(api_key=self.api_key)
        response = client.chat.completions.create(
            model=self.model,
            messages=[{"role": "user", "content": prompt}]
        )
        return response.choices[0].message.content
```

# services/ai_service.py
import os
import requests
from typing import Optional
from config.ai_config import AI_CONFIG

class AIService:
    def __init__(self):
        self.provider = AI_CONFIG["provider"]
        self.model = AI_CONFIG["model"]
        self.temperature = AI_CONFIG["temperature"]
        self.max_tokens = AI_CONFIG["max_tokens"]
        
        if self.provider == "ollama":
            self.endpoint = AI_CONFIG["ollama_endpoint"]
        elif self.provider == "gemini":
            self.api_key = os.getenv("GEMINI_API_KEY")
        elif self.provider == "openai":
            self.api_key = os.getenv("OPENAI_API_KEY")
    
    def generate_feedback(self, problem: dict, code: str, test_results: list) -> str:
        """Generate AI feedback for student submission"""
        from services.prompt_templates import build_socratic_prompt
        
        prompt = build_socratic_prompt(problem, code, test_results)
        
        if self.provider == "ollama":
            return self._call_ollama(prompt)
        elif self.provider == "gemini":
            return self._call_gemini(prompt)
        elif self.provider == "openai":
            return self._call_openai(prompt)
        else:
            raise ValueError(f"Unsupported provider: {self.provider}")
    
    def _call_ollama(self, prompt: str) -> str:
        try:
            response = requests.post(
                f"{self.endpoint}/api/generate",
                json={
                    "model": self.model,
                    "prompt": prompt,
                    "stream": False,
                    "options": {
                        "temperature": self.temperature,
                        "num_predict": self.max_tokens
                    }
                },
                timeout=AI_CONFIG["timeout"]
            )
            response.raise_for_status()
            return response.json()["response"]
        except Exception as e:
            raise Exception(f"Ollama API error: {str(e)}")
    
    def _call_gemini(self, prompt: str) -> str:
        try:
            import google.generativeai as genai
            genai.configure(api_key=self.api_key)
            model = genai.GenerativeModel(
                self.model,
                generation_config={
                    "temperature": self.temperature,
                    "max_output_tokens": self.max_tokens
                }
            )
            response = model.generate_content(prompt)
            return response.text
        except Exception as e:
            raise Exception(f"Gemini API error: {str(e)}")
    
    def _call_openai(self, prompt: str) -> str:
        try:
            from openai import OpenAI
            client = OpenAI(api_key=self.api_key)
            response = client.chat.completions.create(
                model=self.model,
                messages=[
                    {"role": "system", "content": "Bạn là trợ giảng lập trình."},
                    {"role": "user", "content": prompt}
                ],
                temperature=self.temperature,
                max_tokens=self.max_tokens,
                timeout=AI_CONFIG["timeout"]
            )
            return response.choices[0].message.content
        except Exception as e:
            raise Exception(f"OpenAI API error: {str(e)}")


# services/prompt_templates.py
def build_socratic_prompt(problem: dict, code: str, test_results: list) -> str:
    """Build prompt for Socratic AI Tutor"""
    
    # Format test results
    test_summary = []
    for result in test_results:
        status_icon = "✓" if result["status"] == "AC" else "✗"
        test_summary.append(
            f"Test {result['test_case_id']}: {status_icon} "
            f"({result['execution_time']:.2f}s, {result['memory_used']}KB)"
        )
    
    prompt = f"""
Bạn là trợ giảng lập trình theo phương pháp Socratic. Nhiệm vụ của bạn là giúp sinh viên 
hiểu và sửa lỗi code của mình thông qua câu hỏi gợi mở, KHÔNG cung cấp lời giải trực tiếp.

ĐỀ BÀI:
{problem['title']}
{problem['description']}

YÊU CẦU:
- Input: {problem.get('input_format', 'Chưa quy định')}
- Output: {problem.get('output_format', 'Chưa quy định')}
- Giới hạn: {problem.get('time_limit', 'N/A')}s, {problem.get('memory_limit', 'N/A')}MB

CODE SINH VIÊN:
```python
{code}
```

KẾT QUẢ TEST CASES:
{chr(10).join(test_summary)}

Hãy:
1. Phân tích lỗi logic (nếu có)
2. Giải thích nguyên nhân lỗi một cách dễ hiểu
3. Đặt 2-3 câu hỏi gợi mở để sinh viên tự tìm ra lời giải
4. Gợi ý cải thiện code quality (nếu cần)

QUAN TRỌNG:
- KHÔNG viết code giải hộ
- KHÔNG tiết lộ test case ẩn
- Chỉ gợi ý hướng đi
- Giọng điệu khuyến khích, sư phạm
"""
    return prompt

====================================================================================================
PERFORMANCE CONSIDERATIONS
====================================================================================================

OLLAMA (LOCAL):
- Latency: 2-5s per request (depends on hardware)
- Throughput: 1-2 requests/second
- Cost: $0 (but hardware cost)
- Privacy: 100% local

GEMINI FREE TIER:
- Latency: 0.5-2s per request
- Throughput: 15 requests/minute (rate limited)
- Cost: $0 (1.000 requests/day)
- Privacy: Code sent to Google

OPENAI:
- Latency: 0.5-1.5s per request
- Throughput: No rate limit (paid)
- Cost: ~$0.002/1K tokens
- Privacy: Code sent to OpenAI


====================================================================================================
DECISION MATRIX
====================================================================================================

| Factor          | Ollama (Local) | Gemini Free | OpenAI      |
|-----------------|----------------|-------------|-------------|
| Cost            | FREE           | FREE        | Paid        |
| Privacy         | 100%           | Cloud       | Cloud       |
| Latency         | Slow (2-5s)    | Fast (1-2s)  | Fast (1s)   |
| Quality         | Medium         | High        | Very High   |
| Setup           | Complex        | Easy        | Easy        |
| Rate Limit      | None           | 15 req/min  | None        |
| Hardware        | Needs GPU      | Any         | Any         |
| Offline         | Yes            | No          | No          |

RECOMMENDATION: Ollama for MVP (free + privacy), upgrade to Gemini/OpenAI later for quality.
