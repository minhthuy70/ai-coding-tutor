I. THÔNG TIN CHUNG VÀ BỐI CẢNH ĐỀ TÀI
================================================================================

1. Thông tin Đề tài:
- Tên tiếng Việt: Nền tảng Đánh giá Mã nguồn Tự động và Trợ giảng Lập trình Thông minh Tích hợp Trí tuệ Nhân tạo.
- Tên tiếng Anh: AI-Powered Coding Tutor & Automated Source Code Assessment Platform.
- Môi trường áp dụng: Các phòng thực hành máy tính, hệ thống bài tập lớn và kỳ thi thực hành lập trình tại Khoa/Viện CNTT.

2. Bối cảnh và Tính cấp thiết:
a) Hạn chế của hệ thống chấm code truyền thống (như VNOJ, HackerRank, LeetCode):
- Chỉ trả về phán quyết đúng/sai thô sơ: Accepted (AC), Wrong Answer (WA), Time Limit Exceeded (TLE), Runtime Error (RTE).
- Thiếu tính sư phạm: Sinh viên không hiểu vì sao sai ở ca kiểm thử cụ thể, không biết cách khắc phục lỗi logic và không biết code có bị nghẽn độ phức tạp hay không.
- Không đánh giá được chất lượng viết code (Clean Code, PEP 8, Code Smells) và không quét được lỗi bảo mật.

b) Thực trạng sinh viên dùng AI thương mại (ChatGPT / GitHub Copilot):
- Sinh viên có thói quen copy toàn bộ đề bài vào ChatGPT để xin code giải sẵn, làm mất đi tư duy tự giải quyết vấn đề.
- AI thương mại dễ mắc lỗi "ảo giác" (hallucination) và không bám sát giáo trình của trường.

c) Áp lực của Giảng viên và Trợ giảng:
- Lớp học lập trình thường có hàng trăm sinh viên, giảng viên không thể đọc chi tiết từng dòng code để sửa lỗi phong cách và hướng dẫn từng em.

II. MỤC TIÊU CỐT LÕI VÀ TÍNH ĐỘT PHÁ CỦA ĐỀ TÀI
================================================================================

Hệ thống được thiết kế theo mô hình "Hybrid Evidence-Grounded AI" (Đánh giá dựa trên bằng chứng thực thi kết hợp Trí tuệ Nhân tạo Sư phạm), xoay quanh 4 TRỤ CỘT CỐT LÕI:

1. Trụ cột 1 - Web IDE Chuyên dụng:
- Tích hợp Monaco Editor (trình soạn thảo của VS Code) chạy trực tiếp trên nền web.
- Hỗ trợ đa ngôn ngữ (Python, C++, Java, JS), tự động lưu nháp (Autosave) và khóa chỉ đọc (Read-only) ngay khi nộp bài.

2. Trụ cột 2 - Docker Sandbox Cô lập An toàn:
- Chạy code sinh viên trong container cô lập: không có mạng (--network none), chạy quyền user: nobody (non-root).
- Giới hạn cứng tài nguyên: RAM 256MB, CPU 1 core, timeout 2.0s để chặn triệt để mã độc hoặc treo hệ thống (fork bomb).

3. Trụ cột 3 - Auto-Grader và Thu thập Bằng chứng Thực thi (Evidence Engine):
- Chạy tự động bộ Test Cases, thu thập đầy đủ bằng chứng thực tế: RAM đỉnh, thời gian chạy, mã lỗi.
- Phân tích tĩnh (Static Analysis): Đo độ phức tạp Cyclomatic, ước lượng Big-O và quét chuẩn phong cách Flake8.

4. Trụ cột 4 - Socratic AI Tutor & Code Reviewer:
- Trợ giảng AI định hướng tư duy theo phương pháp Socratic: chỉ ra dòng code nghi vấn, đặt câu hỏi gợi ý để sinh viên tự sửa lỗi, tuyệt đối không đưa code giải sẵn.
- Tích hợp RAG để trích dẫn chuẩn giáo trình và quét cảnh báo lỗ hổng bảo mật theo danh mục CWE Top 25 / OWASP.

Bốn Điểm Đột Phá Khác Biệt:
- Đột phá 1 (Tính Sư phạm Socratic): AI gợi mở tư duy, không giải hộ mã nguồn.
- Đột phá 2 (AI có Bằng chứng Thực thi): AI chỉ nhận xét khi đã có dữ liệu chạy thực tế từ Sandbox, loại bỏ phán đoán vô căn cứ.
- Đột phá 3 (Minh bạch Điểm số): Điểm số chính thức do Test Cases và Giảng viên quyết định; nhận xét của AI chỉ mang tính chất tham khảo sư phạm.
- Đột phá 4 (Chi phí 0 Đồng): Vận hành hoàn toàn miễn phí nhờ Google Gemini Flash Free Tier kết hợp Local LLM (Ollama/Llama 3) và ChromaDB.

IV. KIẾN TRÚC KỸ THUẬT VÀ CÔNG NGHỆ SỬ DỤNG (TECH STACK)
================================================================================

1. Luồng Hoạt động Dữ liệu:
- Bước 1: Sinh viên viết code trên Web IDE Monaco và bấm "Nộp Bài".
- Bước 2: FastAPI Server tiếp nhận và đẩy bài nộp vào Hàng đợi Redis / Celery.
- Bước 3: Worker kích hoạt Docker Sandbox chạy Test Cases trong môi trường cô lập, đồng thời Static Analyzer đo độ phức tạp Big-O và Flake8.
- Bước 4: Hệ thống RAG tra cứu cẩm nang môn học từ Vector DB (ChromaDB) theo lỗi thực tế.
- Bước 5: AI Engine tổng hợp Bằng chứng Thực thi + Tri thức RAG để trả về Thẻ Đánh Giá (Clean code, Big-O, CWE) và khung chat Socratic AI Tutor.

2. Bảng Công nghệ Lựa chọn:
- Giao diện Web (Frontend): Next.js 14 (App Router) + TypeScript + Tailwind CSS.
- Trình soạn thảo Code: Monaco Editor (nhúng từ VS Code, hỗ trợ Autosave và Read-only).
- Máy chủ API (Backend): Python FastAPI (xử lý bất đồng bộ ASGI, tự sinh tài liệu Swagger).
- Cơ sở dữ liệu: PostgreSQL 15 (quản lý người dùng, bài tập, lớp học, bài nộp).
- Hàng đợi & Cache: Redis 7 + Celery (chấm bài bất đồng bộ, chống nghẽn khi nhiều người cùng nộp).
- Sandbox thực thi: Docker Container cô lập (--network none, RAM 256MB, CPU 1 core).
- Vector Database: ChromaDB Local (tra cứu tri thức RAG dưới 30ms, không tốn chi phí).
- Trí tuệ Nhân tạo: Google Gemini 1.5 Flash (Cloud Free) / Ollama Llama 3 (Local Offline).

3. Bảng Chi phí Vận hành (Hoàn toàn 0 Đồng):
- Google Gemini 1.5 Flash API: 0 VNĐ (Gói Free Tier 1.500 requests/ngày vĩnh viễn).
- Local LLM (Llama 3 / Mistral): 0 VNĐ (Ollama mã nguồn mở chạy offline).
- ChromaDB Vector Store: 0 VNĐ (Chạy container local).
- Text Embeddings: 0 VNĐ (Mô hình Sentence-Transformers chạy CPU local).
- PostgreSQL & Redis: 0 VNĐ (Mã nguồn mở cài đặt cục bộ).
- Docker Engine: 0 VNĐ (Đóng gói 1 file docker-compose.yml chạy trên mọi máy).

V. MÔ HÌNH KHO TRI THỨC RAG SƯ PHẠM 2 CHIỀU
================================================================================

1. Bản chất của RAG trong Đề tài:
- RAG (Retrieval-Augmented Generation) đóng vai trò "Số hóa cẩm nang sư phạm của trường để AI tra cứu trước khi trả lời":
  + Khi sinh viên gặp lỗi (ví dụ: Maximum recursion depth), hệ thống trích xuất đúng bài học "Đệ quy và Điều kiện dừng".
  + AI dùng đúng thuật ngữ thầy cô dạy trên lớp để hướng dẫn, tránh dùng từ ngữ xa lạ gây bối rối cho sinh viên.

2. Ma trận Tri thức 2 Chiều:
- Chiều 1: Phân loại theo 4 Ngôn ngữ Lập trình:
  + Python: Chuẩn PEP 8, Đệ quy, AST, 100+ mẫu lỗi cú pháp và logic điển hình.
  + C++: Quản lý con trỏ và bộ nhớ, STL Containers, Templates, 100+ lỗi crash thường gặp.
  + Java: Hướng đối tượng OOP, Collections Framework, Exception Handling, 80+ lỗi.
  + JavaScript: ES6+, Bất đồng bộ Async/Await, Scope và Closures, 80+ lỗi.

- Chiều 2: Sáu Trụ cột Chuyên môn Dùng chung:
  + Trụ cột 1: Cấu trúc Dữ liệu & Giải thuật (Mảng, Stack, Queue, Cây, Đồ thị, DP).
  + Trụ cột 2: Phân tích Độ phức tạp Thuật toán (Big-O thời gian và bộ nhớ).
  + Trụ cột 3: Bộ quy tắc Clean Code & Nhận diện Code Smells.
  + Trụ cột 4: An toàn Lập trình & Phòng chống Lỗ hổng Bảo mật (CWE Top 25 / OWASP).
  + Trụ cột 5: Cẩm nang Chẩn đoán & Gỡ lỗi Thực thi (Debugging Patterns).
  + Trụ cột 6: Ngân hàng Câu hỏi Gợi mở Sư phạm theo phương pháp Socratic.
